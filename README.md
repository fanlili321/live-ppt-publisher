# live-ppt-publisher

将已经定稿并导出的银行螺丝钉直播 PPT 归档到飞书、制作腾讯图片文档，并在确认后完成群通知的 Codex Skill。

> 本 README 是给同事看的快速导览；AI 执行时以 [`SKILL.md`](SKILL.md) 为准。

## 能做什么

- 从本地识别同一期直播的 `.key`、PDF 和逐页图片。
- 核对 PDF 页数、图片数量、文件名和页码连续性。
- 按历史命名规范创建飞书共享文件夹并上传全部成品。
- 在腾讯文档“直播”文件夹中创建按页插图的在线文档。
- 设置腾讯文档为“所有人可查看”，并核验位置、页序和权限。
- 将飞书文件夹链接和腾讯文档链接私聊回传给执行人。
- 在用户确认链接无误后，分别通知课程群和渠道群。

## 什么时候使用

只有 PPT 已经定稿，并且 `.key`、PDF、逐页图片都已导出时使用。例如：

- “第 480 期 PPT 已定稿，帮我发布和归档。”
- “从下载文件夹找到这期成品，上传飞书并制作腾讯文档。”
- “更新腾讯文档里的第 12 页，保持原链接不变。”
- “两个链接确认没问题了，通知课程群和渠道群。”

如果 PPT 还需要制作、修改或复核，应分别使用 PPT 制作或复核 Skill，不使用本 Skill。

## 需要提供什么

- 直播期数和正式 PPT 标题；如果文件名及资料中能够唯一确认，可以不重复提供。
- 同一期的 `.key`、PDF 和按页码命名的逐页图片。
- 飞书共享父文件夹位置，以及对应云盘、私聊和群聊权限。
- 腾讯文档账号及“直播”文件夹访问权限。
- 群通知前，需要用户明确确认两个链接无误并同意发送。

## 会产出什么

- 包含 `.key`、PDF 和逐页图片子文件夹的飞书共享目录。
- 位于腾讯文档“直播”文件夹中的逐页图片文档。
- 已验证的飞书共享文件夹链接和腾讯文档链接。
- 私聊回传结果，以及确认后的课程群、渠道群通知结果。

## 标准流程

1. 唯一匹配本地三类成品，核对页数和图片顺序。
2. 创建飞书本期文件夹并上传 `.key`、PDF 和逐页图片。
3. 在腾讯文档“直播”文件夹中新建普通文档，按顺序逐张插图。
4. 核对首图、末图、中间页、图片总数和公开查看权限。
5. 私聊执行人回传两个链接。
6. 等待用户确认链接无误。
7. 以“直播小助手”身份向课程群和渠道群发送对应链接。

## 安装

```bash
git clone https://github.com/fanlili321/live-ppt-publisher.git \
  ~/.codex/skills/live-ppt-publisher
```

安装后可这样触发：

```text
使用 $live-ppt-publisher，发布第 480 期已经定稿并导出的直播 PPT。
```

## 依赖与权限

- Codex Skills 运行环境。
- 飞书云盘、联系人和即时通讯的相应权限。
- 可登录并编辑腾讯文档的浏览器会话。
- 能读取本地 `.key`、PDF 和逐页图片的文件权限。
- 群通知必须能够确认发送者身份为“直播小助手”。

## 重要边界

- 只发布成品，不打开、修改或重新导出 `.key`。
- 三类成品不唯一或页数不一致时停止，不猜测、不凑数。
- 腾讯图片必须逐张顺序插入，不能并发上传导致页序混乱。
- 修改公开查看权限、覆盖文件和发送消息时，必须遵守确认要求。
- 用户确认两个链接无误之前，不向课程群或渠道群发送通知。
- 课程群只发飞书链接，渠道群只发腾讯文档链接。
